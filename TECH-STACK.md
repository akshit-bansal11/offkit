# TECH-STACK.md — Offkit

Authoritative for this repo; overrides the global stack defaults. Versions come from `package-lock.json` and `desktop/Cargo.toml` as of 2026-10-18. Update this file in the same commit as any dependency, service or env-var change.

## Two apps, one registry

| Part | Where | Why this, not the alternative |
| --- | --- | --- |
| Tool registry | `tools.json` | One list (categories, slugs, `platforms`) read by both apps, so a tool's availability can't drift between them. |
| Desktop app | `desktop/` (Rust 2024 edition, Slint 1.18.1) | Native app replaced Electron in 0.2.0: small binary, real file-system access, GPU FFmpeg, no bundled browser. |
| Web app | `src/` (Next.js App Router) | Every tool also runs in the browser through WebAssembly engines; some things (print to PDF) only work well there. |

## Quality gate and CI

- Web: `npm run check:ci` (Biome → ESLint → Stylelint → `tsc --noEmit`), `npm test`, `npm audit --omit=dev --audit-level=high`, `npm run test:e2e:web`.
- Desktop: `cargo fmt --check`, rustfmt over macro-declared modules, `cargo clippy --locked --all-targets -D warnings`, `cargo test --locked` on `windows-latest`.
- **Nothing is built or run on the owner's machine** (concurrent cargo/Node builds crashed it). CI is the gate; `Cargo.lock` and `package-lock.json` are regenerated by `.github/workflows/lockfile.yml`.
